## Что за проект

Кейс Космохакатона (Ростов) — веб-сервис мониторинга NDVI сельхозполей. Две задачи:

1. **Восстановление пропусков.** Заполнить скрытые `primary_ndvi` в тестовом наборе. Автометрика GapScore, RMSE ≥ 0.10 = 0 баллов.
2. **Аномалии.** Найти и объяснить аномальные эпизоды в динамике NDVI. Оценивают эксперты.

ТЗ и критерии разобраны в `docs/` (`01-task-statement.md` … `07-submission-checklist.md`).

Состояние на 2026-09-04: сделано всё по плану. Модель восстановления пропусков (RMSE 0.0716 против 0.0911 у baseline), детектор аномалий, веб-сервис с автосбором данных, отчёты, презентация. Подробности — в `README.md`.

## Неочевидное про данные

- Тестовый файл у нас называется `data/test_dataset.csv`, а в ТЗ он `private_features.csv` — это один и тот же файл (см. `docs/03-data.md`).
- **Координат полей в данных нет**, только анонимные `AOI-xxxx`. Настоящую карту построить нельзя: контуры из OSM/WorldCereal не с чем связать.
- Ключевой рычаг по метрике: `primary_ndvi` = coalesce(S2, Landsat, MODIS), сенсоры смещены друг относительно друга (Landsat +0.037, MODIS +0.083 к S2), а сенсор скрытой точки угадывается по расписанию съёмки (MODIS `doy ≡ 1 mod 16`, Landsat шаг 8, S2 шаг 5). Подробности — в `data/README.md`.
- При обучении: начинать с сенсорной коррекции и делать group-split по полигонам, иначе утечка.

## Окружение

Системный `/usr/bin/python3` без pandas. Рабочее окружение:

```bash
uv venv .venv --python 3.12
uv pip install --python .venv/bin/python pandas numpy scipy matplotlib
.venv/bin/python eda/<script>.py
```

`.venv/` в `.gitignore`.

Локальный просмотр HTML через `file://` в браузере не работает (MCP-браузер это запрещает) — поднимать `python3 -m http.server` и открывать `http://127.0.0.1:PORT/...`. `http.server` отдаёт без charset, поэтому кириллица выглядит кракозябрами — это не баг страницы.
