# Пакет `service` — бэкенд веб-сервиса

Точка входа — `app.py` (`uvicorn service.app:app`) либо `python -m service` (с проверкой окружения при старте).
Интерфейс живёт в [`web/`](../web/), резервный однофайловый — в `service/static/` (адрес `/legacy`).

| Модуль | Роль |
|---|---|
| `app.py` | маршруты API и отдача интерфейса |
| `data.py` | ряды, кривые, нормы, эпизоды и восстановленные значения для экранов |
| `meta.py` | сводка о решении: метрики обеих задач, состав данных, источники |
| `collect.py` | автосбор по произвольному полигону: Sentinel-2, Landsat, MODIS (STAC), ERA5 (Open-Meteo) |
| `s2_cloud_filter.py`, `imagery.py` | отбор дней по доле чистых пикселей и пиксельные карты NDVI/NDMI |
| `osm.py`, `geocoding.py` | контуры OpenStreetMap (Overpass) и поиск места (Nominatim) |
| `weather_source.py`, `weather_metrics.py`, `reporting.py` | суточная ERA5 с кэшем, водный баланс и градусо-дни, данные погодных графиков |
| `analyze_new.py`, `progress.py` | анализ собранного полигона тем же детектором и ход сбора для интерфейса |
| `polygons.py`, `field_store.py`, `anomaly_feed.py` | набор «Мои поля»: сохранение, список, открытие, удаление, отклонения без пересчёта |
| `facts.py` | общий слой фактов о поле — из него берут числа интерфейс, агент, MCP-инструменты и отчёт |
| `agent.py` | ответы на вопросы о поле (`POST /api/ask`); без `OLLAMA_API_KEY` — разбор по правилам |
| `report_html.py` | самодостаточный HTML-отчёт по полю (`GET /api/report/{pid}`), свёрстан под печать |
| `insights.py`, `runtime.py` | краткие выводы для карточек и проверка зависимостей перед приёмом запросов |

Готовность окружения — `GET /api/health`. MCP-инструменты поверх тех же фактов — в [`mcp_server/`](../mcp_server/).

Сбор карты (`POST /api/polygon/{pid}/imagery?year=…`) пишет этапы в
`artifacts/field-imagery/<хеш поля>/v1/<год>/progress.json` через `imagery_progress.py`.
Пока карта не готова, `GET /api/polygon/{pid}/imagery?year=…` возвращает `available: false`
и `progress`: `queued` → `catalog` → `download` → `render` → `done` либо `error`.
Счётчики `processed`/`total` относятся к текущему этапу: проверенным датам или датам подготовленных карт;
`suitable` — число прошедших отбор снимков. Интерфейс опрашивает открытый блок раз в 2 секунды
и после перезагрузки страницы показывает сохранённое состояние. Повторный POST в том же процессе API
присоединяется к существующему заданию. Параллельные независимые экземпляры API общей блокировки не имеют.
