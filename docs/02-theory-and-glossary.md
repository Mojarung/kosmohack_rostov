# Теоретический раздел и глоссарий

> Источник: «Космохакатон — Постановка задачи» ([PDF](source/postanovka-zadachi.pdf)), стр. 6–10.

Ниже приведён минимальный набор понятий и подходов, необходимый для понимания постановки. Он **не задаёт обязательную архитектуру решения**: участники могут применять статистические методы, классические алгоритмы обработки временных рядов, ML/DL или их комбинации.

## Глоссарий

| Термин | Определение |
|---|---|
| **AOI / полигон поля** | Область интереса (Area of Interest), соответствующая контуру сельскохозяйственного участка. В тестовых данных полигоны обозначаются анонимными идентификаторами `anon_polygon_id`. |
| **NDVI** | Normalized Difference Vegetation Index — базовый индекс вегетации растительности. |
| **EVI** | Enhanced Vegetation Index — дополнительный индекс растительности, менее чувствительный к части атмосферных эффектов и насыщению NDVI. |
| **NDWI** | Индекс, используемый для оценки водного сигнала / влажностных особенностей в зависимости от выбранной спектральной формулы. |
| **primary_ndvi** | Основной согласованный ряд NDVI, относительно которого ставится задача восстановления пропусков. |
| **Gap / пропуск** | Дата/наблюдение, для которого целевое значение временного ряда отсутствует. |
| **Climatology / климатическая норма** | Ожидаемое значение индекса для данного периода сезона, рассчитанное по историческим наблюдениям. |
| **Z-score** | Стандартизованное отклонение текущего значения от исторической нормы: `z = (x - mean) / std`. |
| **Аномалия** | Нетипичное относительно нормы состояние временного ряда, например устойчивое снижение вегетационного индекса, потенциально связанное с засухой или угнетением посевов. |
| **RMSE** | Корень из средней квадратичной ошибки; сильнее штрафует крупные промахи восстановления. |

## Теоретическая база

### 1. Восстановление временных рядов (задача 1)

Из-за нерегулярной спутниковой съёмки и облачности значения NDVI наблюдаются не каждый день.

**Простейший baseline** для одиночного пропуска — взять ближайшее известное значение до него и ближайшее после него и усреднить. Именно качество этого baseline соответствует порогу RMSE = 0.10 в метрике (см. [Метрика оценки](04-metric.md)).

Более развитые подходы могут учитывать расстояние по времени, сезонную форму кривой и несколько сенсоров:

- линейная / сплайн-интерполяция;
- фильтр Savitzky–Golay;
- Whittaker smoother;
- модели временных рядов;
- ML-модели.

### 2. Минимальный подход к поиску аномалий (задача 2)

Один из простейших способов — сравнить наблюдаемое значение с исторической нормой для той же фазы сезона, используя формулу:

```
Z = (NDVI_fact − NDVI_climatology_mean) / NDVI_climatology_std
```

Z-score показывает, на сколько стандартных отклонений текущее значение NDVI отличается от климатической нормы для этого полигона и примерно этого момента сезона. Устойчивые и/или сильные отрицательные отклонения являются кандидатами на угнетение растительности.

**Стандартная интерпретация Z-score:**

| Диапазон значений | Статус |
|---|---|
| `Z ≥ −1` | Штатное развитие |
| `−2 ≤ Z < −1` | Угнетение биомассы |
| `Z < −2` | Критическая аномалия |

Участники могут детектировать другие аномалии или применять другой подход, но **нужно будет аргументировать выбор**.

### 3. Контекст аномалии

Отрицательное отклонение NDVI само по себе не объясняет причину. Для более сильного решения полезно сопоставлять сигнал с:

- температурой и осадками ERA5 / ERA5-Land;
- другими индексами;
- соседними датами,

отделяя погодный стресс от выбросов, облаков, смены сельскохозяйственной фазы и ошибок данных.

### 4. Обобщающая способность

Решение должно сохранять качество при переносе на новые полигоны и регионы. Поэтому рекомендуется строить валидацию так, чтобы **часть полей или сезонов полностью оставалась вне обучения** (group / time-based split).

### 5. Самостоятельный сбор обучающих данных

Основной канал — **Google Earth Engine** или прямые открытые источники.

Рекомендуемые коллекции:

| Источник | Идентификатор / назначение |
|---|---|
| Sentinel-2 SR | `COPERNICUS/S2_SR_HARMONIZED` |
| Landsat 8/9 | Level-2 |
| MODIS NDVI/EVI | `MODIS/061/MOD13Q1` |
| ERA5-Land | `ECMWF/ERA5_LAND/HOURLY` (метеоданные) |
| ESA WorldCover | классификация земного покрова |
| ESA WorldCereal | контуры сельскохозяйственных полей |
| OpenStreetMap / Overpass API | контуры полей |
