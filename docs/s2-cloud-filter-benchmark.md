## Почему результат сохраняется

Все каналы строятся в одном ленивом плане odc-stac: общая сетка, группировка solar_day,
исходные версии и порядок мозаики. Сначала вычисляется только SCL. Доля чистых пикселей
внутри полигона — верхняя граница доли пригодных пикселей после проверки red/nir.
Если она ниже 0.6, этот день и прежний алгоритм отбросит. Для оставшихся дней вычисляются
red/nir из того же плана. Окончательную проверку отражений и NDVI делает прежний `_mean_index`.

## Ограничения и включение

В baseline-1 и filter-1 по одному предупреждению rasterio о range-запросе с кодом 206;
в baseline-2 два предупреждения с response_code=0. Итоговые массивы совпали, но сетевые
колебания не позволяют считать 19–24% гарантированным ускорением. Ограничение скорости
со стороны провайдера этим экспериментом не доказано. Другие поля, сезоны и полный сбор
S2+Landsat+MODIS+ERA5 после изменения не замерялись. На почти безоблачном периоде отдельная
фаза SCL может оказаться лишним ожиданием.

Фильтр включён по умолчанию в `_s2_year`. Для возврата прежнего чтения при старте процесса:
`NDVI_S2_CLOUD_FIRST=0`. Локальные тестовые наборы и CI не запускались согласно инструкции
пользователя; выполнены реальные сетевые замеры, сравнение их данных и `git diff --check`.

Воспроизведение из корня репозитория:

```sh
uv run --no-sync python -m scripts.bench_s2_cloud_filter prepare
uv run --no-sync python -m scripts.bench_s2_cloud_filter baseline --name baseline-1
uv run --no-sync python -m scripts.bench_s2_cloud_filter filter --name filter-1
uv run --no-sync python -m scripts.bench_s2_cloud_filter compare --name 1
uv run --no-sync python -m scripts.bench_s2_cloud_filter filter --name filter-2
uv run --no-sync python -m scripts.bench_s2_cloud_filter baseline --name baseline-2
uv run --no-sync python -m scripts.bench_s2_cloud_filter compare --name 2
```

Сырые JSON, NPZ и логи: `artifacts/s2-cloud-filter/`. Следующий полезный замер — полный
первый сбор другого поля: он покажет, сохранился ли выигрыш при параллельной загрузке сезонов
и других источников. Для кратного ускорения одного этого фильтра недостаточно.
