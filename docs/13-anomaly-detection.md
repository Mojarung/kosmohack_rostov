# 13. Детекция и интерпретация аномалий вегетации (задача 2)

Код — пакет [`anomaly/`](../anomaly/), журнал — [`experiments/`](../experiments/README.md) (exp-100…102),
результаты — [`reports/anomalies/`](../reports/anomalies/): `episodes.csv` (эпизоды с причиной и текстом),
`seasons.csv` (фенометрики сезонов), `summary.json`, `figures/`.

```bash
uv run python -m anomaly.run                      # все полигоны train + test → reports/anomalies/
uv run python -m anomaly.evaluate reports/anomalies   # прокси-метрики
uv run python -m anomaly.plots AOI-0065:2024      # график сезона с эпизодами
uv run python -m anomaly.run --loose --out artifacts/anomaly_loose        # вариант для сравнения
uv run python -m anomaly.run --mask-share 0.15 --out artifacts/anomaly_mask15   # устойчивость к пропускам
```

## Что считается аномалией и почему так

ТЗ задаёт минимальный подход: Z-score наблюдения относительно климатической нормы поля и пороги −1/−2.
Мы воспроизвели норму организаторов точно (exp-100: leave-one-year-out среднее сырых `primary_ndvi` в окне
±8 дней по дню года; совпадение статусов 99.7 %) и показали её слабое место: она считается по смеси сенсоров,
а Sentinel-2 читает ниже Landsat на 0.04 и MODIS на 0.08, поэтому четверть «угнетений» в данных — это просто
дни, когда снимал S2 (EDA, раздел 6). Отсюда три решения:

1. **Гармонизация и кривая вместо точек.** Наблюдения приводятся к шкале S2 (смещения оцениваются по
   совместным дням самого полигона), одиночные выбросы (облако, тень: |остаток| > max(0.15, 3·MAD)) помечаются
   артефактами и исключаются, по остальному строится гладкая ежедневная кривая сезона (локальная линейная
   регрессия, полоса 8 дней). Норма — среднее и разброс кривых других лет того же полигона по дню года.
2. **Эпизод, а не точка.** Участок Z < −1 становится эпизодом, если он **устойчивый** (≥ 14 дней и средний
   Z ≤ −1.2) **и/или сильный** (min Z ≤ −1.5) и подтверждён ≥ 2 наблюдениями. Это формулировка ТЗ
   «устойчивые и/или сильные отрицательные отклонения»; одиночные провалы (31 % «аномальных» точек по EDA)
   отсеиваются. Тяжесть: «критическая», если Z < −2 держится ≥ 5 дней.
3. **Причина по правилам с контекстом.** Для каждого эпизода собираются факты:
   - погода ERA5 за 30 дней до и во время эпизода против нормы тех же дат по другим годам (сумма осадков,
     дефицит в %, температура, жаркие дни, сухие серии); у полигонов без ERA5 — медиана по полям региона;
   - фенометрики главного сезона (апрель–август): пик и его дата, старт роста, дата спада — против фенометрик нормы;
   - региональный контекст: медианный Z других полей региона в те же дни и доля полей ниже нормы;
   - второй индекс: отклонение NDWI внутри эпизода от нормы тех же дат (отдельно по S2 и Landsat);
   - артефакты рядом с эпизодом.

Дополнительно `anomaly/shape.py` отмечает 5 % сезонов с нетипичной формой (Isolation Forest по сдвигам пика,
старта и спада, интегралу, амплитуде) с направлением «слабее/сильнее нормы» — как подсказку для нетривиальных
случаев; на список негативных эпизодов это не влияет (exp-103).

## Классы причин

| Класс | Правило | Что значит для агронома |
|---|---|---|
| погодный стресс | дефицит осадков ≥ 40 % или температура на ≥ 1 °C выше нормы с ≥ 5 жаркими днями (окно ≥ 20 дней); уверенность выше, если соседние поля тоже ниже нормы | засуха/жара, региональное явление |
| поле не засеяно / другая культура | с весны кривая плоская: пик главного сезона < 0.35 или < 60 % нормы | пар, смена культуры, невсход |
| севооборот (яровая вместо озимой) | рост начался поздно, но пик достигнут (≥ 85 % нормы) и позже нормы на ≥ 25 дней | смена фазы, **не угнетение** — важно не пугать пользователя |
| ранний спад | пик на уровне нормы, спад на ≥ 15 дней раньше нормы, погодного сигнала нет | ранняя уборка, полегание, болезнь |
| поздний старт | рост на ≥ 15 дней позже нормы, пик в итоге достигнут | поздний сев, холодная весна |
| ослабленный сезон | пик < 70 % нормы или нет других признаков; помечается «локальная причина», если соседи в норме | агротехника, почва, вредители |
| вероятная ошибка данных | ≤ 2 наблюдений внутри и ≥ 2 артефактов рядом | не доверять без проверки |

Каждый эпизод получает текст на русском из фактов (`anomaly/report.py`); при наличии `ANTHROPIC_API_KEY`
языковая модель (`anomaly/llm.py`, Claude через официальный SDK) переписывает его в связное объяснение
с рекомендациями, строго по тем же фактам.

## Проверка качества (экспертной разметки нет)

| Метрика (`anomaly/evaluate.py`) | Значение |
|---|---|
| Сезонов с эпизодом | 44 % (loose-вариант 64 %) |
| Точность против точечных статусов организаторов: доля Z_org < −1 внутри эпизодов (база 17 %) | 0.72 |
| Полнота по критическим точкам организаторов (Z_org < −2) | 0.73 |
| Зависимость доли угнетённых дней от доли S2 в сезоне: у нас / у сырого Z | 0.05 / 0.13 |
| Засушливые годы 2020 и 2024 по частоте эпизодов | 1-е и 2-е место |
| Устойчивость (скрыто 15 % наблюдений): сохранено сезонов / Jaccard дней / совпадение причин | 91 % / 0.89 / 0.89 |

Структура причин подтверждает логику: погодные эпизоды в основном региональные, севооборот и незасеянные
поля — локальные; в спокойные годы (2016, 2023) остаются только локальные эпизоды.

## Показательные случаи

- **AOI-0065, 2024** ([график](../reports/anomalies/figures/AOI-0065_2024.png)): озимая пшеница выше нормы до
  начала июня, затем за три недели с 0.85 до 0.2. Критический эпизод 10.06–20.10, причина — погодный стресс:
  осадки 114 мм при норме 284 (дефицит 60 %), +1.5 °C, 33 жарких дня, сухая серия 19 дней, спад на 49 дней
  раньше нормы; соседние поля тоже ниже нормы.
- **AOI-0043, 2019** ([график](../reports/anomalies/figures/AOI-0043_2019.png)): кривая плоская с апреля,
  пик 0.22 при норме 0.58 → поле не засеяно или занято другой культурой; соседи в норме — причина локальная.
- **AOI-0021, 2017** ([график](../reports/anomalies/figures/AOI-0021_2017.png)): весной Z до −1.6, но пик
  достигнут позже и не ниже нормы → севооборот (яровая культура), не угнетение.

## В сервисе

Те же функции работают для новых территорий: `service/collect.py` собирает S2/Landsat/MODIS и ERA5 по контуру
поля, `service/analyze_new.py` строит кривые, норму по собственной истории поля (2019–2025) и эпизоды с
объяснениями; регионального контекста для одиночного нового поля нет, что отмечается в уверенности причин.

## Ограничения

- Норма требует ≥ 3 лет истории; у 20 полигонов test есть только 2025 год — для них используется средняя кривая
  полей той же культуры (помечается в объяснении), и доля угнетённых дней у них выше (26 % против 17 %).
- ERA5 в данных — среднесуточная температура и осадки на ячейке ~25 км; заморозки, град и суховеи по ним
  не видны, поэтому региональные эпизоды без дефицита осадков получают причину с низкой уверенностью.
- `crop_type` статичен и не отражает севооборот, поэтому фактическая культура года выводится из формы кривой.
