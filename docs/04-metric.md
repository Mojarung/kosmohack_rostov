# Метрика оценки

> Источник: «Космохакатон — Постановка задачи» ([PDF](source/postanovka-zadachi.pdf)), стр. 14.

Автоматическая метрика применяется **только к задаче 1** — восстановлению `primary_ndvi`. Задача 2 (детекция аномалий) оценивается экспертами, отдельный submission по статусам аномалий не требуется.

## RMSE

По всем контрольным точкам тестового набора (строки с `is_synthetic_gap = True`) рассчитывается RMSE между истинным `primary_ndvi_true` и предсказанием команды:

```
RMSE = sqrt((1 / N) * sum((y_true − y_pred)^2))
```

## GapScore

RMSE переводится в нормированный **GapScore от 0 до 30** относительно фиксированного порога `0.10`.

Порог соответствует примерно качеству простого baseline, который восстанавливает пропуск средним двух ближайших известных значений.

```
GapScore = round(30 * max(0, 1 − RMSE_team / 0.10), 2)
```

- решение с `RMSE = 0` получает `GapScore = 30`;
- решение с `RMSE ≥ 0.10` получает `GapScore = 0`.

### Примеры преобразования RMSE в GapScore

| RMSE команды | GapScore |
|---|---|
| 0.10 и выше | 0 |
| 0.08 | 6 |
| 0.05 | 15 |
| 0.02 | 24 |
| 0.00 | 30 |

## Место метрики в итоговой оценке

GapScore — это раздел 0 в [критериях оценки](06-evaluation-criteria.md) и даёт **30 из 100** возможных баллов. Остальные 70 баллов выставляются экспертами.

Практический вывод: baseline «среднее соседей» даёт 0 баллов по метрике. Каждые 0.01 RMSE ниже порога — это +3 балла GapScore.
