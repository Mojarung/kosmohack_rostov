- [x] Batch-инференс: `private_features.csv` → `submission.csv` только для `is_synthetic_gap = True` — *Р0 Метрика* — *`gapfill.predict_saved` (без обучения) и `gapfill.predict`*

   отправляем его, если организаторы сочтут использование опубликованных исторических агрегатов недопустимым.
