## Обязательный функционал

- [ ] Веб-сервис: выбор региона на карте — *Р2 Управление полигонами, Р5 Удобство*
- [ ] Веб-сервис: автоматический поиск готовых с/х контуров для региона (OSM / WorldCereal) — *Р2 Управление полигонами*
- [ ] Веб-сервис: рисование произвольного полигона на карте — *Р2 Управление полигонами*
- [ ] Автосбор спутниковых данных по полигону (Sentinel-2 / Landsat / MODIS) без ручной загрузки датасета — *Р2 Автосбор*
- [ ] Автосбор метеоданных (ERA5 / ERA5-Land) — *Р2 Автосбор*
- [ ] Корректная работа, когда часть источников недоступна — *Р2 Автосбор*
- [ ] Формирование временного ряда NDVI, очистка, восстановление пропусков — *Р0 Метрика*
- [ ] Отображение исходного и восстановленного ряда `primary_ndvi` с визуальным различием точек — *Р5 Удобство*
- [ ] Детекция негативных аномальных периодов — *Р2 Детекция аномалий*
- [ ] Интерпретация аномалий (климатическая норма, погода, несколько источников) — *Р2 Детекция аномалий*
- [ ] Отображение аномалий на карте и графиках — *Р5 Удобство*
- [ ] Batch-инференс: `private_features.csv` → `submission.csv` только для `is_synthetic_gap = True` — *Р0 Метрика*
- [ ] Решение не привязано к одному региону / заранее заданному набору территорий — *Р2 Адаптивность*

## `submission.csv`

- [ ] Колонки ровно: `anon_polygon_id,date,primary_ndvi_pred`
- [ ] Только строки с `is_synthetic_gap = True`
- [ ] Каждая пара `anon_polygon_id + date` ровно один раз
- [ ] Нет `NaN`, пропусков и лишних строк
- [ ] Дата в формате `YYYY-MM-DD`, разделитель — запятая, кодировка UTF-8
- [ ] Локальная валидация на synthetic gaps из train даёт RMSE заметно ниже 0.10
