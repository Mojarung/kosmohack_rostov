## Суть кейса в трёх строках

1. **Веб-сервис**: пользователь выбирает регион и полигон (готовый из OSM / WorldCereal или нарисованный), сервис сам собирает спутниковые и метеоданные, строит ряд NDVI, восстанавливает пропуски и находит аномалии.
2. **Задача 1** (автометрика, 30 баллов): восстановить `primary_ndvi` в контрольных точках `is_synthetic_gap = True` → `submission.csv`. GapScore = `round(30 * max(0, 1 − RMSE / 0.10), 2)`.
3. **Задача 2** (эксперты): найти и объяснить периоды угнетения растительности с опорой на климатическую норму и погоду.

## Ключевые цифры

| Что | Значение |
|---|---|
| Всего баллов | 100 (75 технические + 25 продуктовые) |
| Автометрика GapScore | 0–30, порог RMSE = 0.10 (baseline «среднее соседей» = 0 баллов) |
| Train | 99 955 строк, 39 полигонов, есть `ndvi_zscore` и `status`, которых нет в test |
| Test | 57 185 строк, 78 полигонов, 3 112 контрольных точек (`is_synthetic_gap = True`) |
| Колонки submission | `anon_polygon_id`, `date`, `primary_ndvi_pred` |
| Обязательные точки запуска | веб-сервис + batch-инференс |
| Язык комментариев в коде | русский |
