# 14. Исследовательский отчёт

Кейс Космохакатона (Ростов): веб-сервис мониторинга вегетационной динамики сельхозполей. Отчёт собирает ход
работы по обеим задачам; подробности — в [EDA](08-eda-report.md), [модели восстановления](12-gapfill-model.md),
[детекции аномалий](13-anomaly-detection.md) и [журнале экспериментов](../experiments/README.md).

## 1. Задача и протокол оценки

- **Задача 1.** Восстановить скрытые `primary_ndvi` в контрольных точках test (`is_synthetic_gap = True`):
  3 112 в первой версии файла, **2 323 во второй** (обновление организаторов 2026-09-05: 20 полигонов, история
  2010–2024; см. [docs/03](03-data.md)). Автометрика GapScore = round(30·max(0, 1 − RMSE/0.10), 2).
  Baseline «среднее двух соседей» даёт RMSE 0.093 → 2 балла.
- **Задача 2.** Найти негативные аномальные периоды вегетации и объяснить причины (оценивают эксперты).
- **Сервис.** Выбор региона и полигона на карте, автосбор спутниковых и метеоданных, ряд NDVI, восстановление,
  аномалии на графиках и карте.

Локальный протокол задачи 1: синтетические пропуски — 15 % известных точек (как доля контрольных точек в test),
замаскированная строка теряет все динамические колонки; оценка на двух независимых масках; RMSE общий,
взвешенный под состав test (85 % новых полигонов, 30 % 2025 года) и усечённый (без выбросов самого target).

## 2. Данные и что в них важно (EDA)

Train: 39 полигонов, 2010–2024, 30 520 известных точек; test (первая версия): 78 полигонов (39 общих + 39 новых),
2010–2025, 17 641 известная точка и 3 112 контрольных; test (вторая версия): 20 из новых полигонов, 2010–2024,
13 164 известных точки и 2 323 контрольных, без колонок нормы. Ключевые наблюдения:

1. `primary_ndvi` — сырое значение одного сенсора по приоритету S2 → Landsat → MODIS (100 % строк), а не сглаженный ряд.
   Сенсоры смещены: Landsat +0.037, MODIS +0.083 к S2. Сенсор скрытой точки угадывается по циклам съёмки (92 % правилом, 98 % классификатором).
2. Контрольные точки «плотные»: медиана до ближайшего соседа 2 дня. Задача — локальное шумоподавление с учётом сенсора.
3. Ошибка baseline определяется сменой сенсора (0.065 при соседях того же сенсора, 0.112 при других), а не расстоянием.
4. Координат нет; у 33 полигонов нет ERA5; 20 полигонов test — только сезон 2025.
5. Z-score организаторов зависит от сенсора (S2 −0.23, MODIS +0.52): четверть «угнетений» — артефакт смены спутника.
6. 2020 и 2024 — засушливые сезоны (30 % и 28 % аномальных точек).

## 3. Использованные данные

Только данные кейса: train **и известные точки test** (это те же полигоны и годы, где нужно предсказывать;
их известные строки доступны как признаки); после обновления test известные точки первой версии файла добавлены
как контекст (итого 61 325 точек), а опубликованные ответы к ней в обучении не используются. Внешние спутниковые
ряды привязать к анонимным полигонам нельзя.
Проверенные готовые модели (Chronos-2 zero-shot, TabPFN, Presto/Galileo) пользы не дали или неприменимы
([exp-006](../experiments/exp-006-second-mask-pretrained.md)). Для сервиса внешние источники используются
напрямую: Sentinel-2 L2A, Landsat C2 L2 и MODIS MOD13Q1 (Planetary Computer; для Sentinel-2 запасной каталог Earth Search), ERA5 (Open-Meteo), OSM (Overpass).

## 4. Baseline и его ограничения

| Метод | RMSE | GapScore |
|---|---|---|
| среднее двух соседей (ТЗ) | 0.093 | 2.0 |
| линейная интерполяция по времени | 0.094 | 1.7 |
| климатология | 0.159 | 0 |
| глобальная сенсорная коррекция без обучения | 0.084 | 4.9 |
| интерполяция того же сенсора (oracle-сенсор) | 0.084 | 4.9 |

Ограничения baseline: не знает сенсора скрытой точки, не использует остальные сенсоры и индексы, не видит
формы сезона и соседних полей. Гипотезы: (а) угадывать сенсор и приводить соседей к его шкале; (б) гладкая
кривая сезона по всем сенсорам; (в) MODIS как окно композита; (г) общий «шум дня» по другим полигонам;
(д) обучение на известных точках test; (е) две разные модели в смеси.

Финал (exp-008, им и получен `submission.csv`): LightGBM с 427 признаками (соседи по сенсорам, форма сезона,
кригинг по времени, «шум дня» соседних полей) + ResidualSeasonNet, учащаяся на остатке дерева, смесь 0.5/0.5 и
калибровка по историческим агрегатам полигона; обучение на всех 61 325 известных точках. RMSE на отложенной
выборке 0.0437 (GapScore 16.88), разброс по трём маскам 0.0036. Разбор и ограничения калибровки —

давала 0.0553 → GapScore 13.41.
Усечённый RMSE 0.046 при потолке 0.041 (точки с соседом в один день): дальше — шум одного наблюдения и выбросы target (1.2 % точек дают 43 % ошибки).

## 6. Детекция аномалий (задача 2)

Норма организаторов воспроизведена точно (LOO по году, ±8 дней, статусы 99.7 %) и заменена гармонизированной:
кривая сезона в шкале S2 без артефактов → Z к норме по истории полигона → эпизод «устойчиво и/или сильно»
→ причина по правилам (ERA5 против нормы тех же дат, фенометрики главного сезона, региональный контекст
«все поля или только это», NDWI, артефакты). Классы: погодный стресс, поле не засеяно/другая культура,
севооборот (яровая вместо озимой — не угнетение), ранний спад, поздний старт, ослабленный сезон, ошибка данных.
Проверка без разметки (1 248 сезонов, 78 полигонов): сезонов с эпизодом 44 %, precision к точечным статусам
организаторов 0.70, recall критических 0.73, зависимости от сенсора нет (corr 0.05 против 0.18 у сырого Z),
засушливые 2020/2024 — первые два года, устойчивость к скрытию 15 % наблюдений 91 %. Примеры: AOI-0065 2024 (засуха), AOI-0043 2019
(не засеяно), AOI-0021 2017 (севооборот) — [docs/13](13-anomaly-detection.md).

## 7. Обоснование финальной конфигурации

- LightGBM: l2, lr 0.03, 63 листа, min_data_in_leaf 40, feature_fraction 0.6 — подбор Optuna (24 trials) лучше не нашёл.
- SeasonNet: 128 каналов, 10 дилатированных свёрток + 2 слоя трансформера, dropout 0.25, 600 эпох; EMA и
  увеличенная сеть — без выигрыша, шум входа вредит.
- Веса смеси 0.5/0.5 устойчивы (0.4–0.6 равнозначны) на двух масках.
- Детектор: пороги ТЗ (−1/−2), критерий устойчивости 14 дней и средний Z ≤ −1.2 или min Z ≤ −1.5 —
  даёт 44 % сезонов вместо 64 % без потери полноты по критическим точкам.

## 8. Ограничения и развитие

- RMSE ниже ~0.05 недостижим: шум одного наблюдения и выбросы в скрытых ответах.
- Норма требует ≥ 3 лет истории; для новых полей сервис собирает 2019–2025.
- ERA5 не видит заморозки, град, суховеи — региональные эпизоды без дефицита осадков получают низкую уверенность.
- Развитие: K-fold стекинг SeasonNet + LightGBM; культура года по форме кривой; больше индексов (EVI, NDWI) в
  кривой; LLM-объяснения с рекомендациями (слой готов, нужен ключ).

`anomaly.run` / `anomaly.evaluate` / `anomaly.plots`, `uvicorn service.app:app`. Seed 42 везде, версии
зафиксированы в `pyproject.toml` + `uv.lock`, образ — `Dockerfile`.
