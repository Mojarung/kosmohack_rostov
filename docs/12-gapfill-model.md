# 12. Модель восстановления `primary_ndvi` (задача 1)

Код — пакет [`gapfill/`](../gapfill/), журнал экспериментов — [`experiments/`](../experiments/README.md).
Числа в этом документе — на 2026-09-05; актуальные результаты в журнале.

## Идея

`primary_ndvi` — не сглаженный ряд, а сырое значение одного сенсора (S2 → Landsat → MODIS по приоритету).
Восстановить скрытую точку значит ответить на три вопроса:

1. **Какой сенсор снимал в этот день?** По циклам съёмки того же полигона-года (S2 — шаг 5 дней, Landsat — 8,
   MODIS — фиксированная сетка дней года с шагом 16) сенсор угадывается на 92 % простым правилом и на 98 %
   классификатором.
2. **Какое «истинное» значение NDVI в этот день?** Локальные линейные кривые по гармонизированному ряду
   (S2+Landsat, MODIS, все сенсоры; полосы ядра 6 и 15 дней), соседи по каждому сенсору, окно композита
   MODIS [d, d+15], собственная климатология полигона и аномалия сезона, ERA5.
3. **Какой «шум дня» был у этого сенсора?** Остатки других полигонов, снятых тем же сенсором в ту же дату,
   коррелируют с остатком целевой точки (0.32–0.48): атмосфера и геометрия съёмки общие для региона.
   Координат нет, поэтому «соседство» полигонов оценивается парной корреляцией остатков.

## Данные для обучения

Train (30 520 известных точек) **плюс известные точки test** (17 641): test — это те же полигоны и годы,
где нужно предсказывать, и его известные строки легально доступны как признаки. Внешние спутниковые ряды
привязать нельзя (полигоны анонимны, координат нет).

Обучающие примеры: случайные маски по 15 % известных точек (как доля контрольных точек в test);
замаскированная точка теряет все динамические колонки, признаки считаются по оставшимся. 20–30 масок дают
120–180 тыс. примеров.

## Валидация

Одна маска 15 % играет роль контрольных точек, остальные — контекст; обучающие маски — по контексту.
Метрики: общий RMSE, RMSE **взвешенный под состав test** (70 % новых полигонов с историей, 7 % новых
полигонов только с 2025 годом, 15 % старых полигонов в 2025 году, 8 % новых полигонов в 2025),
усечённый RMSE (без |ошибка| > 0.3 — выбросы самого target).

## Модели

| Модель | Файл | Что это |
|---|---|---|
| LightGBM | `gapfill/train.py`, `predict.py` | 243 табличных признака, l2, 20 масок, target обрезан до [−0.1, 1] |
| CatBoost (GPU) | `gapfill/train_cb.py` | те же признаки, вторая табличная модель для смеси |
| SeasonNet | `gapfill/nn_model.py`, `nn_data.py` | полигон-год как «изображение» 213 дней × 33 канала; дилатированные свёртки + трансформер; каждую эпоху новая маска |
| Смесь | `gapfill/ensemble.py`, `make_submission.py` | веса по НМНК на валидации |

## Запуск

```bash
uv sync --group ml --group dl                       # LightGBM, CatBoost, torch cu130
uv run python -m gapfill.train --n-masks 20 --clip -0.1 1.0 --out lgb_v3   # валидация LightGBM
uv run python -m gapfill.nn_model --epochs 600 --dropout 0.25 --out nn_v2   # валидация нейросети
uv run python -m gapfill.ensemble lgb_v3 nn_v2                              # веса смеси
uv run python -m gapfill.predict --n-masks 30 --rounds 5500 --seeds 0 1 2 --out final_lgb
for s in 0 1 2; do uv run python -m gapfill.nn_model --final --epochs 600 --dropout 0.25 --seed $s --out final_nn; done
uv run python -m gapfill.make_submission final_lgb:0.5 final_nn:0.5         # → submission.csv
uv run pytest tests -q
```

Промежуточные признаки кэшируются в `artifacts/features/` (не в git, пересчёт ~2 с на маску).

## Результаты (валидация, маска seed 777, 7 224 точки)

| Модель | RMSE | test-like | trim |
|---|---|---|---|
| среднее двух соседей (baseline ТЗ) | 0.092 | — | — |
| интерполяция того же сенсора (oracle-сенсор) | 0.084 | — | — |
| LightGBM v3 | 0.0574 | 0.0644 | 0.0492 |
| CatBoost v1 | 0.0582 | 0.0653 | 0.0495 |
| SeasonNet, один seed | 0.0598–0.0601 | 0.0660–0.0670 | 0.0501 |
| **0.5 · LightGBM + 0.5 · среднее 4 seeds SeasonNet** | **0.0552** | **0.0622** | **0.0463** |

Потолок: точки с соседом в одном дне восстанавливаются с усечённым RMSE 0.041 — это шум одного
наблюдения; 1.2 % точек-выбросов target дают 43 % квадратичной ошибки и не предсказуемы.
