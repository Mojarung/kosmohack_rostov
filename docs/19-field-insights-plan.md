# Дополнения к анализу поля

Сохраняем выбор полей, модель и основной график NDVI. Ветка: `feat/field-insights`.

1. **Карта снимка.** Сворачиваемая панель для географических полей: NDVI, NDMI и изменение NDVI относительно предыдущего пригодного снимка. Sentinel-2 L2A, сетка 20 м, облака/тени/снег исключаются по SCL. Показываем дату, чистую площадь, среднее и легенду. Изменения считаются только на общих чистых пикселях; отдельно указываем площадь сравнения. Карта помогает выбрать место осмотра, не диагностирует причину.
2. **NDMI.** (NIR − SWIR1) / (NIR + SWIR1), среднее чистых пикселей. Дополнительная вкладка существующего графика, без интерполяции облачных дней. Исторический диапазон допускается только при наличии минимум трёх предыдущих загруженных сезонов; при одном сезоне показываем только наблюдения. NDWI из кейса не переименовываем.
3. **Погодные события.** Отметки дней Tmax ≥ 30 °C и Tmin < 0 °C. Это явно подписанные погодные пороги для просмотра, не пороги повреждения культуры. При отсутствии Tmin/Tmax отметок нет. Кликом можно приблизить период.
4. **Почва.** ERA5-Land через Open-Meteo: средняя модельная влажность слоя 0–100 см, взвешенная по толщине слоёв 7/21/72 см. Только полные сутки (24 значения каждого слоя), затем сравнение с десятью предыдущими годами на ту же календарную дату. Единицы м³/м³. Сетка порядка 10 км, не датчик поля и не рекомендация полива.
5. **Загрузка.** Снимки загружаются по запросу, кэшируются на диске; повторное открытие не требует сбора. Обработка снимков в отдельном процессе, статус и повтор после ошибки в интерфейсе. Анонимные AOI без координат продолжают показывать доступные ряды.

Проверки: маски/отверстия полигона, формулы и общая площадь сравнения, пропуски погоды, API, E2E на существующем географическом поле и кейсе, разные годы, ошибки/повтор, мобильный экран. Реальные внешние источники проверяются отдельно от воспроизводимых тестов расчёта.
