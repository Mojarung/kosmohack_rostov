# Данные соревнования и формат submission

> Источник: «Космохакатон — Постановка задачи» ([PDF](source/postanovka-zadachi.pdf)), стр. 11–13.

## Общее описание

Участникам с начала хакатона предоставляются два набора данных:

| Файл | Назначение |
|---|---|
| `train_dataset.csv` | Обучающий (reference) набор |
| `private_features.csv` | Тестовый набор |

Данные представлены в табличном виде: **одна строка = один анонимизированный полигон в одну дату**. Строка однозначно идентифицируется комбинацией `anon_polygon_id + date`.

### Состав признаков

| Группа | Признаки |
|---|---|
| Идентификаторы | `anon_polygon_id`, `date` |
| Спутниковые индексы | Sentinel-2, Landsat, MODIS |
| Метеоданные | ERA5 |
| Календарные признаки | `year`, day-of-year |
| Целевая переменная | `primary_ndvi` |
| Климатическая норма | характеристики климатической нормы, `n_reference_years` |
| Служебные | `is_synthetic_gap` |
| Статичные | `crop_type` |

В `train_dataset.csv` целевые значения `primary_ndvi` известны. В `private_features.csv` для контрольных строк с `is_synthetic_gap = True` значение `primary_ndvi` скрывается, а динамические и вычисляемые признаки этой строки маскируются.

## Train (обучающий датасет)

Участникам предоставляется reference-набор `train_dataset.csv`:

- **99 955 строк** с известным `primary_ndvi` и сопутствующими признаками;
- дополнительно содержит `ndvi_zscore` и `status`, **которых не будет в test**.

Его можно использовать для построения baseline, обучения и проверки пайплайна. При необходимости команды могут расширять обучающую выборку за счёт открытых источников.

### Рекомендации по использованию и расширению train

- использовать доступные контуры сельскохозяйственных полей из OpenStreetMap / Overpass API, ESA WorldCereal либо собственные полигоны;
- собирать дополнительные временные ряды Sentinel-2, Landsat и MODIS по выбранным полигонам;
- добавлять погодные признаки ERA5 / ERA5-Land или данные других открытых метеоисточников;
- самостоятельно создавать валидационные synthetic gaps из известных точек, чтобы сравнивать методы восстановления;
- фиксировать источники данных, параметры фильтрации облаков, агрегации и все этапы предобработки для воспроизводимости.

Допускается использование других открытых источников и публичных предобученных моделей, если это не нарушает их лицензии и правила соревнования. **Все внешние данные и модели должны быть перечислены и описаны в отчёте и README.**

## Test (тестовый датасет)

Участникам с начала хакатона предоставляется тестовый датасет `private_features.csv`.

- Для контрольных точек значение `primary_ndvi` скрывается, строка помечается `is_synthetic_gap = True`, а остальные динамические и вычисляемые признаки в этой строке также маскируются.
- Участник должен восстановить `primary_ndvi` **только для строк с `is_synthetic_gap = True`**.
- Правильные значения `primary_ndvi` для контрольных точек участникам не предоставляются. Ground truth хранится у организаторов и используется только для автоматической оценки решений на платформе.

### Что оценивается, а что нет

- Для проверки задачи 1 команда формирует `submission.csv` с предсказанными значениями `primary_ndvi` для всех контрольных точек и загружает его на платформу. Платформа автоматически сопоставляет предсказания со скрытыми правильными ответами и рассчитывает итоговые RMSE и GapScore.
- **Естественные пропуски**, возникшие из-за отсутствия пригодного спутникового наблюдения, сами по себе **не являются контрольными точками** автоматической метрики.
- Для задачи 1 оцениваются только строки, специально помеченные `is_synthetic_gap = True`.

## Формат `submission.csv`

Файл формируется **только для строк, где `is_synthetic_gap = True`**, и должен содержать три колонки:

| Колонка | Описание |
|---|---|
| `anon_polygon_id` | Анонимный идентификатор полигона |
| `date` | Дата контрольной точки в формате `YYYY-MM-DD` |
| `primary_ndvi_pred` | Восстановленное значение `primary_ndvi` (вещественное число) |

Требования к файлу:

- пара `anon_polygon_id + date` должна встречаться в submission **ровно один раз** и соответствовать контрольной строке тестового набора;
- пропуски, `NaN` и дополнительные строки **не допускаются**;
- разделитель CSV — запятая;
- кодировка — UTF-8.

### Пример

```csv
anon_polygon_id,date,primary_ndvi_pred
AOI-0001,2025-06-14,0.543218
AOI-0037,2025-07-03,0.391005
```
