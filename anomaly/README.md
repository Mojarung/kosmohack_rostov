# Пакет `anomaly` — детекция и объяснение аномалий вегетации (задача 2)

Метод и проверка — в [docs/13](../docs/13-anomaly-detection.md), результаты — в
[`reports/anomalies/`](../reports/anomalies/).

Конвейер: ряд полигона → гармонизация сенсоров и гладкая кривая → Z к норме по истории поля →
эпизоды «устойчиво и/или сильно» → причина по правилам → текст на русском.

| Модуль | Роль |
|---|---|
| `config.py` | пороги эпизода, окна, константы интерпретации |
| `series.py` | ряд полигона: приведение Landsat/MODIS к шкале S2, отбраковка артефактов, ежедневная кривая |
| `climatology.py` | две нормы: воспроизведённая норма организаторов и гармонизированная по другим годам |
| `detect.py` | Z-score, выделение эпизодов, фенометрики сезона |
| `weather.py` | ERA5 до и внутри эпизода против нормы тех же дат |
| `indices.py` | NDWI как второй независимый индекс |
| `shape.py` | нетипичная форма сезона (Isolation Forest по отклонениям фенометрик) |
| `report.py` | причина по правилам и готовый текст объяснения |
| `llm.py` | то же объяснение языковой моделью по структурированным фактам (нужен `OLLAMA_API_KEY`) |
| `run.py`, `evaluate.py`, `plots.py` | пакетный прогон, прокси-метрики без разметки, графики сезонов |

```bash
uv run python -m anomaly.run                                 # все полигоны → reports/anomalies/
uv run python -m anomaly.evaluate reports/anomalies          # прокси-метрики детектора
uv run python -m anomaly.plots AOI-0065:2024 AOI-0043:2019   # графики сезонов с эпизодами
```
