# E2E погодных графиков

Сервис: `uv run --locked --group service python -m service`.

Сценарий [weather_charts.js](weather_charts.js) запускается в MCP Playwright:
`browser_run_code_unsafe({"filename":"<абсолютный путь>/tests/e2e/weather_charts.js"})`.
Это функция от настоящего Playwright `page`; основные проверки используют реальные HTTP-ответы.
Один запрос погоды намеренно заменяется ошибкой 503 для проверки повторной загрузки.
Нужны исходные данные кейса; сохранённое географическое поле проверяется дополнительно, если оно есть.

Проверяются загрузка сервиса, исходная карта, два одновременно видимых графика и исходные данные в подробностях,
сверка отображаемых осадков/тепла/исторического среднего/сухого периода с исходными дневными данными,
смена поля и сезона, один сезон без исторической нормы, поле без погоды, сворачивание пояснений,
переключение осадков/тепла/баланса с ET₀, общее наведение, приближение эпизода и сброс масштаба,
повторная загрузка после ошибки, экран 390 px без горизонтальной прокрутки, ошибки JavaScript.

Формулы и пропуски отдельно: `uv run --no-sync pytest tests/test_weather_metrics.py -q`.

## Площадь снижения и динамика отклонения

`field_insights.js` запускается тем же способом. Нужны сохранённое географическое поле и собранные
в интерфейсе карты 2025 года. Сценарий проверяет новые карточки, смену сезона/поля, карту NDMI и изменения,
отсутствие сравнения для первого снимка, легенду, мобильный экран, защиту от запоздалого ответа,
POST загрузки и повтор после ошибки. Основные данные и PNG настоящие; отсутствие кэша и 503
явно имитируются только для проверки обработки ошибок. Скриншоты сохраняются в `artifacts/e2e/`.

Расчёты наблюдаемого Z и общей площади двух снимков: `uv run --no-sync pytest tests/test_insights.py -q`.
