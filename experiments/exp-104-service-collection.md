# exp-104. Сервис: автосбор данных для нового поля и устойчивость к отказам источников

Дата: 2026-09-05. Код: `service/collect.py`, `service/analyze_new.py`. Тестовое поле ~1.5 км² под Ростовом
(39.85–39.87° в.д., 47.35–47.36° с.ш.), сезоны 2019–2025 (апрель–октябрь).

| Вариант | Время | Результат |
|---|---|---|
| последовательно, 10 м, чтение сцен по одной (1 сезон) | S2 ≈ 5 мин (прервано) | слишком медленно для интерактива |
| dask-параллельно по сценам, S2 в 20 м из обзорных уровней COG (1 сезон) | S2 34 сцены за 32 с, Landsat 25 за 18 с, ERA5 2 с | MODIS падал: int8 с nodata 255 → читать в int16 |
| + параллельно по годам (4 потока), 7 сезонов | 176 с | S2 и Landsat отвалились целиком: одна битая сцена прерывает загрузку года |
| + `fail_on_error=False` (битые сцены пропускаются), 7 сезонов | **176 с** | **S2 174 сцены, Landsat 152, MODIS 176, ERA5 1 497 дней; 5 эпизодов** |

Устойчивость: при недоступном источнике ряд строится по остальным (проверено: только MODIS + ERA5 → 6 эпизодов),
в интерфейсе выводится пометка, какие источники сработали.

Найденные эпизоды на тестовом поле согласуются с региональной картиной из данных кейса: 2024 — «погодный стресс»
(6 июня — 23 сентября, дефицит осадков), 2020 — весеннее и осеннее угнетение. Регионального контекста для одиночного
нового поля нет, поэтому уверенность локальных причин ниже.
