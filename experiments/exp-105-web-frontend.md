# exp-105. Новый интерфейс: React + MUI X Charts + AntV L7, запуск всего продукта одной командой

Дата: 2026-09-05. Задача: заменить резервный одностраничный HTML полноценным приложением, не потеряв
ни одного требования ТЗ, и собрать весь продукт в один образ.

## Стек и почему так

| Слой | Выбор | Причина |
|---|---|---|
| Каркас | React 19.2 + Vite 8 + TypeScript | самый ходовой стек, быстрая сборка, лёгкое разделение на чанки |
| Графики | MUI X Charts 9 (community) | композиция `ChartsContainer` + собственные SVG-слои поверх тех же шкал: своя форма и цвет для каждого сенсора, полосы эпизодов, лента нормы. Pro-функции (зум, reference area) не нужны и платные |
| Карта | AntV L7 2.29 + l7-draw 3.1 | WebGL-рендер полигонов, готовый инструмент рисования; подложка — растровые тайлы OpenStreetMap (ключи не нужны) |
| Данные | TanStack Query 5 | кэш на сессию, единая обработка ошибок FastAPI |
| Анимации | GSAP 3.15 | фоновые «пузырьки» на transform/opacity, слой `position: fixed` вне потока — кадр остаётся композиторным |
| Иконки | нет | все иллюстрации нарисованы в проекте (`web/src/components/art/`), иконочные шрифты и SVG-спрайты не подключаются |

Версии проверены через Context7 и npm перед установкой (правило проекта).

## Что измерено

Сборка (`vite build`, gzip):

| Чанк | gzip | Когда грузится |
|---|---|---|
| index (приложение) | 35 КБ | сразу |
| vendor (react, router, query) | 80 КБ | сразу |
| charts (MUI X Charts + d3) | 142 КБ | при открытии поля |
| l7 (карта, WebGL) | 916 КБ | только на экране «Новая территория» |
| CSS | 1.6 КБ | сразу |

Первый экран — около 115 КБ gzip. Карта самая тяжёлая часть: она вынесена в отдельный чанк и подключается
через `React.lazy`, поэтому на обзор и разбор поля не влияет. Альтернатива MapLibre GL (~200 КБ gzip)
рассматривалась, но L7 даёт готовый `l7-draw` и одинаковый API для полигонных слоёв.

Проверка в браузере (Playwright, системный Chrome, 1440×960): пять экранов открываются без ошибок в консоли
(0 ошибок), карта поднимается на тайлах OSM, графики сезона рисуются с наблюдениями, нормой и полосами эпизодов.

## Решения по интерфейсу

1. **Каскадное появление блоков** (`IntersectionObserver`) оставлено только для крупных секций. На списке из
   78 карточек полей оно мешало: карточки оставались невидимыми до прокрутки. Список выводится сразу,
   первые 24 карточки, дальше — по кнопке.
2. **Объяснение эпизода** дублировалось: связный текст плюс те же аргументы списком. Аргументы убраны под
   раскрывающийся блок «разобрать по аргументам».
3. **Таблица аномалий**: объяснение обрезается тремя строками, разворачивается по клику — иначе строка занимает
   пол-экрана.
4. **Прогресс сбора данных**: реального стрима у `POST /api/analyze` нет, поэтому показываются стадии по времени
   и счётчик секунд — пользователь видит, что процесс идёт, и знает про 1–3 минуты.
5. **Резервный интерфейс** (`service/static/index.html`) сохранён и доступен по `/legacy`: если эксперт не собрал
   фронтенд, сервис всё равно открывается.

## Сборка одной командой

`docker compose up --build`: этап `node:24-alpine` собирает `web/dist`, этап `ghcr.io/astral-sh/uv:python3.14`
ставит зависимости (`ml`, `geo`, `service`, `dl`) и получает статику. FastAPI отдаёт `web/dist` и клиентские
маршруты (`/field/AOI-0005` открывается прямой ссылкой). Набор полей пользователя вынесен в именованный том.

## Что осталось

- Тайлы OpenStreetMap ходят напрямую с `tile.openstreetmap.org`: для публичного развёртывания нужен свой кэш
  или другой провайдер (политика использования тайлов).
- Экрана сравнения нескольких полей между собой нет; это следующий шаг для продуктовой части.
