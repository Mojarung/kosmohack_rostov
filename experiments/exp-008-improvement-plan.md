# exp-008. Улучшение восстановления NDVI: план и протокол

Дата: 2026-09-05. Исходная ревизия: `2f6b2a4c8a1d10d945d44a3bc826e4d652c3e986`.

Цель: уменьшить **полный RMSE**, первоначальная практическая планка — 0.05. RMSE 0.01 рассматривается как
желаемый результат, достижимость которого ещё не подтверждена. Бюджет пользователя — до шести часов.
Обучение и оценка моделей разрешены; разработка и запуск программных тестов не входят в работу.

## Отправная точка

По сохранённому отчёту exp-007: LightGBM 0.0554, SeasonNet 0.0590, смесь 0.0541;
на страте новых полигонов с историей смесь 0.0557. Это локальная валидация, не оценка платформы.
Готовые финальные веса обучались на всех известных точках, поэтому оценивать ими качество на скрытой части
этих же известных точек нельзя: требуется обучение заново с исключением валидационных значений.

Файл `test_features (1) (2).csv` идентичен `data/test_features_new.csv` после нормализации CRLF → LF.
SHA-256 нормализованного содержимого: `a4ca0b0cce98716653eb50c1f261a5d297db9bd04f1657f8cc593dcd90d4651d`.
В исходном пайплайне этот набор уже используется; дублирование не добавляет наблюдений.

## Порядок экспериментов

1. Воспроизвести контрольный LightGBM, измерить полный RMSE отдельно на всех точках и на 20 полигонах
   текущего test-файла. Проверить маскирование всех динамических колонок, включая погоду.
2. Использовать все доступные сенсорные наблюдения: вторичные Landsat/MODIS не должны теряться только
   потому, что в тот же день доступен Sentinel-2. Добавить отдельные кривые и соседей для каждого сенсора.
3. Усилить пространственный контекст: индивидуальные отношения между полями, сенсорные остатки,
   перенос измерений близких по истории полигонов. Все отношения оценивать только по видимому контексту.
4. Проверить ограниченный набор параметров, масок, функций потерь и весов; отбирать по полному RMSE,
   сохраняя диагностику выбросов отдельно. Не объявлять усечённый RMSE конкурсной метрикой.
5. При наличии времени проверить независимую модель/нейросеть для смеси. Сравнить с лучшим одиночным
   вариантом и подтвердить выигрыш на второй маске без её использования для подбора.
6. Обучить выбранный вариант на всех известных точках, сохранить веса, воспроизводимую команду,
   отдельный submission и отчёт. Исходные веса и submission сохранять для сравнения.

## Правила оценки

- Разработка: маска 777. Подтверждение выбранного варианта: маска 999; при спорном результате — 2026.
- Валидационные значения исключаются из обучения, видимого контекста, корреляций и заново рассчитываемых
  признаков. Опубликованные организаторами нормы содержат информацию о скрытых значениях; их использование
  выделено в отдельную, явно отмеченную калибровку и не считается обычным ML-обобщением.
- Основные показатели: полный RMSE всех скрытых наблюдений; полный RMSE строк `split=test`
  (именно текущие 20 полигонов); исторический `testlike` для сопоставления с exp-007.
- Дополнительно: ошибки по сенсорам и годам, вклад крупных промахов, разброс по полигонам.
- Без истинных ответов на 2323 конкурсных пропуска итоговый RMSE платформы остаётся неизвестным.

Результаты текущего запуска сохраняются в `artifacts/research/`; итоговые выводы будут записаны отдельно.

**Итог:** выбран ансамбль 0.6 LightGBM (427 признаков) + 0.4 ResidualSeasonNet и отдельная устойчивая
калибровка опубликованными агрегатами. Целевой RMSE на масках 777 / 999 / 2026:
**0.045802 / 0.042223 / 0.043179**; без агрегатов — **0.056954 / 0.053385 / 0.055460**.
Полный разбор и воспроизведение: [docs/16-model-improvement.md](../docs/16-model-improvement.md).
Веса — `models/improved/`; исходная модель не заменена. Условия допустимости калибровки нужно уточнить
у организаторов; закрытые конкурсные ответы при оценке этих чисел не использовались.

### Особенность опубликованных агрегатов

В старом файле `data/test_dataset.csv` у этих 20 полигонов за 2025 год опубликованы исторические mean/std,
которые включают значения 2010–2024 годов, в том числе теперь скрытые. Формула — другие годы и окно ±8 дней
по дню года, стандартное отклонение ddof=0. На 14431 полностью известных окнах максимальная ошибка среднего
составила 4.03e-16; суммы квадратов также совпали до машинной точности.

Это **информация о скрытых ответах в опубликованных признаках**, а не свидетельство способности модели
предсказывать случайный шум. Калибровка будет доступна отдельно от обычного ML-инференса и привязана к
отпечаткам исходных файлов. Настоящие ответы на новый test и результат платформы пока неизвестны.

Обычная проекция на известные суммы уменьшила test-RMSE 0.059237 → 0.053621. Жёсткая подгонка дисперсий
ухудшила его до 0.0677: выброс можно назначить неверному году. Усреднение допустимых решений с тяжёлыми
хвостами и отдельная оценка неопределённости снизили ошибку сильнее. Масштаб ошибки обучен на внутренних
полигон-годах, не использованных регрессором, внешняя маска 777 в этом обучении отсутствует.

Повторное прогнозирование после однозначного восстановления части контекста дало только ~0.0002 выигрыша
на нужных полигонах. Его низкий общий RMSE ~0.025 нельзя трактовать как обобщающую способность модели:
агрегаты раскрывают почти все отложенные значения старых полигонов. Эта ветка пока экспериментальная.
