# exp-103. Устойчивость кривой, NDWI как второй индекс, нетипичная форма сезона, калибровка без истории

Дата: 2026-09-05.

## 1. Полигоны без истории (20 полигонов test только с 2025 годом)
Норма по культуре даёт им 25.6 % угнетённых дней против 19.4 % у полигонов с историей в том же 2025 году
(средний Z −0.11 против −0.05; std нормы по культуре 0.153 против 0.113). Вычитание регионального медианного Z
(−0.22 в 2025) перекорректирует до 16.3 %. Решение: норму по культуре оставить, в объяснении источник нормы
помечается, а региональный контекст («соседи тоже ниже нормы») сам снижает уверенность локальных причин.

## 2. Устойчивость кривой
Локальная линейная регрессия на редких точках экстраполировала за физический диапазон (амплитуда сезона до 1.9).
Исправлено: при эффективном числе точек < 2 наклон не оценивается (взвешенное среднее), кривая обрезается до
[−0.1, 1], база фенологии — 5-й перцентиль. Признаки gapfill не затронуты (параметр `min_points` по умолчанию 0).
Число эпизодов 474 → 480, прокси-метрики без изменений (precision 0.71, recall критических 0.73, corr с долей S2 0.05).

## 3. NDWI как второй индекс (`anomaly/indices.py`)
Для эпизода считается отклонение NDWI наблюдений внутри эпизода от нормы тех же дат по другим годам,
отдельно по S2 и Landsat (сенсоры читают NDWI по-разному). Отклонение ≥ 0.05 попадает в аргументы:
«индекс влажности NDWI ниже нормы на 0.08 — растительность суше обычного (водный стресс)».

## 4. Нетипичная форма сезона (`anomaly/shape.py`)
Isolation Forest по отклонениям фенометрик (пик, сдвиги пика/старта/спада, интеграл, амплитуда, средний Z, доля
дней ниже нормы), верхние 5 % сезонов (48 из 948): 30 «слабее нормы», 18 «сильнее нормы»; 15 сезонов без
эпизодов — в основном необычно сильные сезоны или сдвинутые фазы. Флаг показывается в интерфейсе как
дополнительный сигнал с направлением; на детекцию негативных эпизодов не влияет.

## Итог по детектору (strict, 948 сезонов)
480 эпизодов: погодный стресс 120, ранний спад 100, севооборот 96, ослабленный сезон 69, не засеяно 54,
поздний старт 35, ошибка данных 6; критических 121. Тесты: `tests/test_anomaly.py` (синтетический полигон
с провалом в одном году: эпизод находится только в нём).

## 5. Правки по итогам ручной проверки текстов (2026-09-05, позже)
- NDWI организаторов антикоррелирует с NDVI (растёт при потере зелёной массы): формулировка «влажность выше обычного»
  заменена на «второй индекс подтверждает потерю зелёной массы»; падение NDWI при низком NDVI — повод заподозрить артефакт.
- Порядок аргументов: сначала главный признак причины, потом региональный контекст, потом погода.
- Затяжная сухая серия (≥ 20 дней без осадков > 1 мм в окне «30 дней до + эпизод») считается погодным стрессом
  сама по себе: погодный стресс 120 → 173 эпизодов, «ослабленный сезон без причины» 69 → 43, ранний спад 100 → 73.
  Прокси-метрики детектора не меняются (причины не влияют на выделение эпизодов).
