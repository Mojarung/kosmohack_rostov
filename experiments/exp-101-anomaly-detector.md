# exp-101. Детектор эпизодов: гармонизированная кривая, критерий «устойчиво и/или сильно», прокси-метрики

Дата: 2026-09-05. Код: `anomaly/` (series → climatology → detect → weather → report → run, оценка `anomaly/evaluate.py`).

## Схема
1. Ряд полигона в шкале S2 (смещения Landsat/MODIS по совместным дням полигона, сжатые к глобальным),
   LOO-остатки относительно локальной линейной кривой (полоса 8 дней), артефакты = |остаток| > max(0.15, 3·MAD).
2. Ежедневная кривая сезона по наблюдениям без артефактов; норма — среднее и std кривых других лет
   того же полигона по дню года (std не ниже 0.04); для полигонов без истории — среднее кривых полигонов той же культуры.
3. Z = (кривая − норма)/std по дням; участки Z < −1 (разрывы ≤ 5 дней сливаются) → эпизод, если
   **устойчивый** (≥ 14 дней и средний Z ≤ −1.2) **и/или сильный** (min Z ≤ −1.5), при этом ≥ 7 дней и ≥ 2 наблюдений внутри.
4. Причина по правилам (погода ERA5 за 30 дней до + эпизод против нормы тех же дат по другим годам; фенометрики
   главного сезона апрель–август: пик, старт роста, спад; артефакты рядом) + текст на русском.

Экспертной разметки нет, поэтому метрики косвенные (`anomaly/evaluate.py`).

| Метрика | loose (Z < −1, ≥ 7 дней) | **strict (устойчиво и/или сильно)** |
|---|---|---|
| Сезонов с эпизодом | 64 % | **44 %** |
| Эпизодов на сезон | 0.82 | 0.50 |
| Коротких (< 14 дней) | 14 % | 3 % |
| Recall точек организаторов с Z_org < −1 / < −2 | 0.65 / 0.76 | 0.52 / **0.73** |
| Precision: доля Z_org < −1 среди точек внутри эпизодов (база 17 %) | 0.67 | **0.72** |
| corr(доля угнетённых дней, доля S2 в сезоне): у нас / у сырого Z организаторов | 0.05 / 0.13 | 0.05 / 0.13 |
| Ранг засушливых лет 2020 / 2024 | 1 / 3 | **1 / 2** |

Статус организаторов воспроизведён (норма ±8 дней LOO): корреляция Z 0.9998, совпадение статусов 99.65 %.

Кейсы из EDA: AOI-0043 2019 → «поле не засеяно / другая культура» (пик главного сезона 0.22 при норме 0.58);
AOI-0065 2024 → критическая, «погодный стресс» (осадки 114 мм при норме 284, +1.5 °C, 33 жарких дня, сухая серия
19 дней, спад на 49 дней раньше нормы).
