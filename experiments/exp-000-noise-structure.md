# exp-000. Структура шума primary_ndvi: что вообще предсказуемо

Дата: 2026-09-05. Данные: train + известные точки test (48 161 наблюдение: Landsat 20 088, S2 19 050, MODIS 9 023).
Остаток = наблюдение − линейная интерполяция двух соседей **того же сенсора** в том же полигоне-годе (окно ±20 дней).
Скрипт: `scratchpad/hyp_check.py` (разовый, не в репозитории).

Std остатка по сенсорам: Landsat 0.072, S2 0.071, MODIS 0.061 — это «потолок» простых интерполяций (≈0.063 у коллеги).

| Гипотеза | Результат | Вывод |
|---|---|---|
| H1. У S2 есть смещение по орбите (остаток `day_num % 5`) внутри полигона | std средних по группам 0.0083 против 0.0066–0.0086 при перестановке | **Нет сигнала**, признак не нужен |
| H1b. Landsat `day_num % 8` | 0.0070 против 0.0048 при перестановке | Слабый сигнал, можно дать как признак |
| H3. Общий «шум дня»: остаток полигона коррелирует со средним остатком других полигонов в ту же дату, тот же сенсор | corr S2 **0.32**, Landsat **0.48**, MODIS **0.46**; объяснённая дисперсия 10 / 23 / 21 % | **Главный резерв**: атмосфера и геометрия съёмки общие для всех полей в дату. Для S2 в одной ячейке ERA5 corr 0.45 |
| H4. Остаток S2 против осадков дня | corr −0.12; в дни с осадками >1 мм средний остаток S2 −0.031, MODIS +0.019 | Небольшой, но полезный признак (облачное загрязнение) |
| H2. Чему соответствует MODIS: точке d или окну композита | RMSE после снятия смещения: в точке d 0.102, среднее [d, d+15] **0.084**, max [d, d+15] 0.095, [d−8, d+8] 0.100 | MOD13Q1 датирован **началом** 16-дневного окна; для точек на сетке MODIS считать среднее гармонизированного ряда за [d, d+15] |

Следствия для модели:
1. Признак «средний остаток других полигонов в ту же дату по каждому сенсору» (с LOO-остатками относительно гладкой кривой полигона).
2. Для гипотезы «сенсор = MODIS» отдельная оценка — среднее S2/Landsat за [d, d+15].
3. Осадки дня из соседних строк ERA5 (у полигонов с сеткой).
4. Орбитальные остатки S2 не использовать.
