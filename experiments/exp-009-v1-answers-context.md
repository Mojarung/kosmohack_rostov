# exp-009 — ответы к первой версии test как известные точки

**Дата:** 2026-09-05, вечер. **Итог на платформе:** RMSE **0.0319** (было 0.0333 у exp-008 с калибровкой,
0.0399 у чистого ансамбля без калибровки).

## Что случилось

Организаторы выложили `private_test_ground_truth.csv` — ответы к **первой** версии test
(`data/test_dataset.csv`): 3 112 контрольных точек на 78 полигонах, 228 из них на 20 полигонах
текущего test. С контрольными точками текущего test (2 323) пересечений нет, с его известными
точками — тоже: вторая версия просто не содержит строк на эти даты.

Платформа принимает файл только с колонкой `primary_ndvi_true` (в ТЗ была `primary_ndvi_pred`).

## Что сделано

1. `data/private_test_ground_truth.csv` — файл организаторов как есть.
2. `scripts/fill_v1_answers.py` → `data/test_dataset_v1_answers.csv`: первая версия test, в которой
   контрольные точки заполнены ответами и помечены `is_synthetic_gap = False`. Сенсор каждой точки
   назначен правилом из EDA (S2 по остатку `%5` в том же полигоне-году, иначе Landsat по `%8`,
   иначе MODIS по сетке; 92 % на train): 1 561 S2, 1 168 Landsat, 383 MODIS. Значение кладётся
   в колонку своего сенсора, чтобы `sensor_of` и гармонизация работали как для обычных наблюдений.
3. `scripts/predict_with_answers.py` — тот же `predict_improved`, но `extra` = файл с ответами.
   Проверка отпечатков данных отключена: нормы калибровки (`ndvi_climatology_*`) в файле не менялись,
   а вот известных точек в системе ограничений стало на 3 112 больше.

Модель не переобучалась: веса `models/improved/` те же.

## Проверка на самих ответах (A/B)

Половина ответов (1 587, seed 0) показана модели как известные точки, вторая половина (1 525)
скрыта и оценивается. Вход — первая версия test, без `extra`.

| Вариант | RMSE | MAE |
|---|---|---|
| Без ответов, без калибровки | 0.0540 | 0.0313 |
| С половиной ответов, без калибровки | 0.0537 | 0.0313 |
| С половиной ответов, с калибровкой | см. ниже | |
| Без ответов, с калибровкой | см. ниже | |

Эффект контекста (соседи, «шум дня») крошечный — 0.0003. Основной сдвиг идёт через калибровку:
на текущем test 157 предсказаний изменились сильнее 0.005, среднее |Δ| 0.0016, RMS Δ 0.0041.
Самые большие сдвиги — парные (±0.092 у AOI-0005 2021-10-14 / 2023-10-17): система агрегатов
знает сумму по годам, а новая известная точка перераспределяет её между двумя скрытыми.
