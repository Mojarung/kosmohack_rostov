# exp-102. Региональный контекст, погода региона для полигонов без ERA5, «севооборот» как отдельный класс

Дата: 2026-09-05. Код: `anomaly/run.py` (два прохода), `anomaly/report.py`, `anomaly/weather.py`.

## Что добавлено
1. **Региональный контекст.** Для каждого эпизода — медианный ежедневный Z других полигонов в те же даты
   (≥ 3 полей) и доля полей со средним Z < −1. Z ≤ −0.7 или доля ≥ 50 % → «явление региональное»;
   Z ≥ −0.3 → «соседи в норме, причина локальная». Это отвечает на главный вопрос агронома:
   «это у всех так или только у меня».
2. **Погода региона.** У 22 полигонов ERA5 нет вовсе; для них берётся медиана ERA5 по всем полям с погодой
   на каждый день (источник пишется в объяснение: «ERA5 региона»). Погодная атрибуция стала доступна для
   всех эпизодов: 332 по ERA5 полигона, 142 по ERA5 региона.
3. **Севооборот.** Если рост начался поздно, но пик достигнут (≥ 85 % нормы) и позже нормы на ≥ 25 дней —
   это яровая культура вместо привычной озимой: смена фазы, а не угнетение (ТЗ требует их разделять).

## Результат (strict-критерий, 948 сезонов, 474 эпизода)
| Причина | Эпизодов | Из них «локальных» / «региональных» |
|---|---|---|
| погодный стресс (засуха/жара) | 117 (было 70) | 13 / 55 (остальные смешанные) |
| ранний спад | 103 | 42 / 7 |
| **севооборот (яровая вместо озимой)** | 96 (новый класс) | 77 / 2 |
| ослабленный сезон без явной причины | 77 (было 143) | 38 / 0 |
| поле не засеяно / другая культура | 53 | 31 / 0 |
| поздний старт | 22 | 13 / 2 |
| вероятная ошибка данных | 6 | — |

Логика подтверждается структурой: погодные эпизоды в основном региональные, севооборот и незасеянные поля —
локальные. Средний региональный Z эпизодов по годам: 2020 −0.58, 2014 −0.49, 2010 −0.46, 2024 −0.46 против
2016 +0.52, 2023 +0.40 — засушливые годы региональные, спокойные годы дают только локальные эпизоды.

Прокси-метрики не изменились (детектор тот же): сезонов с эпизодом 44 %, precision 0.72, recall критических 0.73.
Устойчивость к пропускам (скрыто 15 % наблюдений, seed 1): сохраняется 91 % отмеченных сезонов, Jaccard дней
эпизода медиана 0.89, совпадение причин 0.89.
