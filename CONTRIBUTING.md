# Как внести изменения

Проект — сервис мониторинга NDVI сельхозполей для Космохакатона (Ростов). Ниже — правила,
по которым живёт репозиторий; они же описаны в `CLAUDE.md`.

## Окружение

Всё через **uv**, Python 3.14. Никаких `pip` и `python` напрямую.

```bash
uv sync --group service --group agent --group torch   # полное окружение разработчика
uv run --no-sync python -m pytest tests/ -q            # тесты, около 8 секунд
cd web && npm ci && npm run build                      # интерфейс (Node 20+)
```

На Windows кириллица в консоли: запускайте с `PYTHONIOENCODING=utf-8`. Файлы пишите только в UTF-8.

## Ветки и коммиты

- Основная ветка одна: `main` (на GitVerse она называется `master`). Рабочие ветки короткоживущие,
  вливаются через merge и удаляются.
- Перед пушем: `git pull`, слить, прогнать тесты, затем `git push`.
- Сообщение коммита в формате `тип: что сделано` — типы `feat`, `fix`, `perf`, `refactor`, `docs`,
  `test`, `chore`. Тело коммита объясняет **почему** и приводит числа замеров, если они были.

## Код

- Комментарии и docstring на русском языке — это критерий жюри.
- Функции до 50 строк, файлы до 400 строк, входные DataFrame не мутируем.
- Пути от `Path(__file__)` или из конфигов, никаких абсолютных путей.
- Ключи и токены только в окружении или `.env` (файл в `.gitignore`). В коде ключей нет.
- Новый код покрывается тестами без сети: внешние сервисы и модель подменяются.

## Что куда

| Каталог | Что там |
|---|---|
| `gapfill/` | восстановление пропусков NDVI, метрика (`gapfill.metrics`) |
| `anomaly/` | детектор периодов снижения и объяснения по правилам |
| `service/` | FastAPI: сбор данных, факты, агент, отчёт |
| `mcp_server/` | MCP-инструменты для внешних клиентов |
| `web/` | интерфейс на React + Vite |
| `tests/` | pytest, всё без сети |
| `docs/` | ТЗ, отчёты, разбор решений |
| `experiments/` | журнал экспериментов с номерами exp-NNN |

## Артефакты

Графики и `summary.json` коммитятся, чтобы отчёт читался без запуска. Крупные промежуточные
файлы — нет (`artifacts/` в `.gitignore`). Модели в `models/` помечены в `.gitattributes`
как двоичные: Git не должен трогать в них переводы строк.
