# Безопасность

## Как сообщить об уязвимости

Напишите любому участнику команды напрямую или откройте issue с пометкой «безопасность».
Не публикуйте детали уязвимости в открытом виде до исправления. Ответим в течение двух дней.

## Что важно знать

- Ключи внешних сервисов (языковая модель Ollama Cloud) читаются только из окружения
  или файла `.env`, который не попадает в git. В коде ключей нет; пример — `.env.example`.
- Сервис не требует регистрации и ключей для основной работы: без ключа модели объяснения
  формируются по правилам. Спутниковые и метеоданные берутся из открытых каталогов.
- Сервис принимает от пользователя геометрию поля и текст вопроса. Геометрия проверяется
  по размеру участка, текст ограничен по длине; в отчёт всё экранируется.
- Данные пользователя (собранные поля) хранятся локально в `artifacts/` и не отправляются
  никуда, кроме запросов к каталогам снимков и, при наличии ключа, к языковой модели.

## Если ключ утёк

Отозвать его в личном кабинете провайдера и выпустить новый. Старый удалить из `.env`.
